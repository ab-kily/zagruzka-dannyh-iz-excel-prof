# Загрузка данных из Excel (проф)

Внешняя обработка **1С:Предприятие 8.3** (управляемое приложение) для универсальной загрузки данных из файлов Excel/CSV/ODS в справочники, документы и регистры сведений по метаданным конфигурации.

Готовый файл: [`ЗагрузкаДанныхИзExcelПроф.epf`](./ЗагрузкаДанныхИзExcelПроф.epf)

## Быстрый старт

1. Скачайте `ЗагрузкаДанныхИзExcelПроф.epf` из этого репозитория.
2. В 1С: **Файл → Открыть** → выберите `.epf` (или подключите как внешнюю обработку).

## Возможности

- Чтение файлов **xlsx / xls / csv / ods** через табличный документ (без COM Excel)
- Выбор объекта: справочник, документ, регистр сведений
- Сопоставление колонок файла с реквизитами (маппинг)
- Поиск и создание ссылочных значений, кэш ссылок
- Загрузка построчно с отдельными транзакциями
- Предпросмотр данных перед загрузкой
- Шаблоны настроек в хранилище общих настроек
- Подсказки по полям формы

## Состав выгрузки

Исходники — выгрузка внешней обработки в файлы (формат конфигуратора):

| Файл | Назначение |
|------|------------|
| `ЗагрузкаДанныхИзExcelПроф.xml` | Корневой файл обработки (точка загрузки) |
| `ЗагрузкаДанныхИзExcelПроф.ObjectModule.txt` | Модуль объекта |
| `ЗагрузкаДанныхИзExcelПроф.Form.Форма*.xml` / `*.txt` | Форма и модуль формы |
| `ЗагрузкаДанныхИзExcelПроф\` | Иерархическая копия исходников (удобно для просмотра) |

## Как собрать `.epf`

1. Откройте **Конфигуратор**.
2. **Файл → Открыть** → выберите `ЗагрузкаДанныхИзExcelПроф.xml`  
   либо **Конфигурация → Загрузить внешнюю обработку из файлов** (в зависимости от версии).
3. Сохраните как внешнюю обработку: `ЗагрузкаДанныхИзExcelПроф.epf`.
4. Запускайте `.epf` в режиме **1С:Предприятие** (управляемое приложение).

После правок исходников снова загрузите файлы в конфигуратор и пересохраните `.epf`. Старый `.epf` без пересборки обновления не подхватит.

## Как пользоваться

1. Выберите файл Excel/CSV/ODS.
2. Укажите лист (для Excel) и при необходимости отметьте «первая строка — заголовки».
3. Выберите тип данных и объект метаданных (например, справочник).
4. Настройте маппинг: колонка файла → реквизит объекта.
5. Для ссылочных реквизитов задайте способ поиска / создания.
6. Просмотрите данные и нажмите **Загрузить**.

Заголовки колонок в файле должны совпадать с именами реквизитов (или явно сопоставьте их в маппинге). Опечатки в именах реквизитов конфигурации (например, `Еденица` вместо `Единица`) мешают автосопоставлению.

## Требования

- Платформа **1С:Предприятие 8.3**, управляемые формы
- Не зависит от БСП
- Чтение через OpenXML / `ТабличныйДокумент.Прочитать`
